# @deepseek-ai/dsh-client-ui-locale-pt

[English](README.md) | 中文

## 概述

为 Web GUI 的语言选择器添加巴西葡萄牙语，并为随附客户端插件暴露的每个 locale 命名空间注册一份 pt-BR 字典。缺失的键由 locale 运行时回退到英文。

## 使用本包

本包随客户端树一起激活，无需配置。打开「设置 → 通用」，选择「Português (Brasil)」。

## 模型体验

无，因为 locale 层不注册任何面向模型的内容。

#### KV 缓存影响

无；本包既不组装也不发送任何提供方请求。

## 已知限制与后续工作

- **翻译以英文键集为准** —— 上游新增而此处尚无 pt-BR 条目的命名空间键会回退到英文，直到在此补充。

**运行时不变量：** 不发布伴随包。语言定义与每个命名空间字典都注册为受管效果，其释放由插件测试证明；选择、回退查找与持久化由 locale 运行时负责，不存在第二份副本。
